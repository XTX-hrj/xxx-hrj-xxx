# SpeedMind AI Turbo — Roadmap

The product will remain free to trial until the user experience and operational controls are reliable. No payment, subscription, recharge, or automatic billing features are planned for the current stage.

## v0.5.1 — Usability

- Build a responsive registration and login interface.
- Add an API key management page.
- Display remaining free quota and usage history.
- Add clear error states and onboarding instructions.

## v0.6.0 — Durable usage data

- Persist request logs and usage records.
- Track provider, model, route, latency, token usage, and status.
- Add per-user usage history and admin diagnostics.
- Define retention and privacy policies.

## v0.7.0 — Trial administration

- Configurable free quotas and per-user rate limits.
- Abuse prevention and account-level throttling.
- Provider cost estimation and budget alerts for the operator.
- No end-user charging in this milestone.

## v0.8.0 — Operations dashboard

- User dashboard and service health views.
- Provider configuration and routing controls.
- Aggregated metrics suitable for multi-worker deployment.
- Structured logs and monitoring integration.

## v0.9.0 — Deployment readiness

- Reproducible Docker build and deployment guide.
- HTTPS and production configuration.
- Database backup/restore test.
- Load, failure-injection, and security tests.

## v1.0.0 — Public release decision

Release only after live provider tests, security review, deployment verification, monitoring, and support processes are complete. Any later monetization decision is separate and requires explicit product approval.
